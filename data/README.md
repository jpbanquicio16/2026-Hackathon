# Data provenance

`winequality-white.csv` is the unmodified white-wine file from the
[UCI Wine Quality dataset](https://archive.ics.uci.edu/dataset/186/wine+quality).
It was supplied in the user's Downloads directory. Attribution: Cortez, P., Cerdeira,
A., Almeida, F., Matos, T., & Reis, J. (2009). Wine Quality [Dataset]. UCI Machine
Learning Repository. https://doi.org/10.24432/C56S3T.

Dataset license: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The repository's MIT license covers code, not this dataset. The prepared training
and prediction files in `examples/` are adaptations with the same attribution;
the exact transformations and checksum are recorded in `docs/CASE_STUDY.md`.
